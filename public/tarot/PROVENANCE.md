# Rider–Waite–Smith card artwork

The 78 Tarot images in this directory were sourced from Wikimedia Commons' `Rider-Waite-Smith tarot deck (TaionWC)` category on 2 September 2026 through the MediaWiki API.

- Source category: https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)
- Recorded license metadata for every downloaded source: `Public domain`
- Copyrighted: `False`
- Attribution required: `False`

The application uses resized, grayscale WebP derivatives. Card names, positions, and interpretations are original application text and are rendered separately.
