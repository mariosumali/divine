# Card-back source

`owen-jones-ornament-60.jpg` is an unmodified 1280px Wikimedia Commons
thumbnail of plate 60 from Owen Jones's _The Grammar of Ornament_ (1868).
The application uses different crops from this single plate to give each deck
a related but distinct back.
