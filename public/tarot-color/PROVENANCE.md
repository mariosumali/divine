# Rider–Waite–Smith color card artwork

The 78 color scans in this directory are resized WebP derivatives of the public-domain 1909 Rider–Waite deck mirrored by the `sixseeds/tarot-api` repository. Every local filename was resolved from that repository's complete `cards.json` manifest on 2 September 2026.

- Manifest and source repository: https://github.com/sixseeds/tarot-api
- Original artwork: Pamela Colman Smith, 1909
- Repository image notice: public domain
- Independent public-domain reference: https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck

The color scans are an optional visual deck. The application renders its own card names, positions, and original interpretations separately.
